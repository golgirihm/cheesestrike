# Execution's last stand in the HUD: with bots, a teammate and an enemy go
# down (CheeseStrikeDown), for the row along the top and the scoreboard,
# then the host. Run with tools/play.ps1 -Script tools/play/downed_row.txt
# -Bots -Extra "?Mode=Execution?Bots=5?BotSkill=0".
